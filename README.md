# architecture-standart

Проектная работа спринта 3: цифровая трансформация банка «Стандарт» — перевод открытия депозитов и накопительных счетов в онлайн-каналы (интернет-банк и сайт).

| Директория | Содержание |
|---|---|
| [Task1](Task1) | Карта текущего IT-ландшафта и схема интеграции приложений с участниками процессов |
| [Task2](Task2) | Архитектурно значимые требования в формате FURPS+ |
| [Task3](Task3) | ADR концептуальной архитектуры MVP открытия депозитов онлайн (C4: контекст, контейнеры) |
| [Task4](Task4) | ADR передачи ставок в кол-центр и партнёрский кол-центр (C4: контекст, компоненты), список задач по системам, RoadMap |

Диаграммы хранятся в формате draw.io (`.drawio`, открываются в [app.diagrams.net](https://app.diagrams.net)), для удобства просмотра рядом лежат PNG.
