# Список крупных задач по системам

Идентификаторы задач совпадают с [RoadMap](RoadMap.drawio) ([PNG](RoadMap.png)). Сроки — месяцы от старта проекта.
Этапы: **MVP-3** — открытие депозитов онлайн (ADR задания 3); **MVP-4** — передача ставок в кол-центры (ADR этого задания); **Цель** — целевое состояние через год (автоматическое открытие депозитов без бэк-офиса).

## Критический путь MVP
T1 → T3 → T10 → T13 → T15 → T24 → T25. Для кол-центров: T7 → T10 → T20 и T21 → T9 → T11 → T22. Маркетинговая кампания стартует только после T20 и T22, чтобы кол-центры были готовы к росту звонков.
